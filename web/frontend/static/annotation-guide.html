标注指南

如何为决策模型提供标注数据

CSV 字段说明
字段 类型 必填 格式 示例
state_text str 是 自然语言文本 "选择技术方案"
actions str 是 竖线 | 分隔 "保守|激进|均衡"
optimal_action int 是 0-based 索引 0
transition_probs str 是 动作间 | 分隔，动作内逗号分隔 "0.7,0.3|0.4,0.6|0.2,0.8"
expected_returns str 是 逗号分隔 "5.5,3.2,7.8"
CSV 完整示例
state_text,actions,optimal_action,transition_probs,expected_returns
"用户需要选择最佳的方案来处理技术选型。当前选项：1. 保守策略；2. 激进策略；3. 均衡策略","保守策略|激进策略|均衡策略",0,"0.7,0.3|0.4,0.6|0.2,0.8","5.5,3.2,7.8"
"基于市场竞争分析，应选择最佳投资策略","保守投资|激进投资|均衡投资",2,"0.5,0.5|0.3,0.7|0.6,0.4","4.0,6.5,5.2"
"投资者需要配置资产组合，选择最优方案","集中配置|分散配置|对冲配置",1,"0.6,0.4|0.2,0.8|0.5,0.5","3.5,7.1,5.0"
流程说明
1
用户输入决策场景 → 模型预测最优选项及概率分布
2
用户发现结果有误 → 提交反馈（标注正确选项）
3
反馈积累到 50 条 → 自动触发模型微调
4
模型热更新 → 下次预测使用新模型
